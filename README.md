# LumniJato

Sistema de gestão para lava-jato. O Módulo 1 é a Gestão de Finanças.

- Requisitos: [`docs/requisitos/`](docs/requisitos/)
- Como preparar o ambiente e ligar o banco: [`docs/dev/setup.md`](docs/dev/setup.md)

```bash
corepack enable   # uma vez, para ter o pnpm
pnpm install
pnpm verificar    # lint, tipos e testes de todo o monorepo
```
